FAQ

When does this get updated?

+

Links get updated every weekend. Expect updates on weekdays too. I will eventually make a Google Form so you can report broken links.

Is Vantahub free?

+

Yes! Vantahub is and will always be free. It is created by ahw101 and supported by the community.

Why use Vantahub?

+

We offer a curated collection of the best unblocked sites in one place, making it easy to bypass filters at school or work.

Why are there adverts?

+

Adverts help cover hosting costs and domain fees. You are free to use ad-blockers if you prefer.

Are the games safe?

+

All links are manually checked. However, since many are external, always practice safe browsing habits.

How do I request a game?

+

You can contact ahw101 on GitHub or wait for the official request form to be released soon!

Does it work on Chromebooks?

+

Yes, Vantahub is designed specifically to work well on managed devices like school Chromebooks.

What is a Proxy?

+

A proxy allows you to browse other websites through a different server, helping you unblock restricted content.

Why is a site not loading?

+

Sometimes links get blocked by your network. Try a different link from the "All Sites" section.

Can I contribute?

+

Absolutely! Check out the GitHub repository and feel free to suggest new links or improvements.
